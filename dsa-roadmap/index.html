DSA Roadmap for Beginners: 11 Topics in the Right Order

This roadmap puts data structures and algorithms topics in a specific sequence so each topic builds on what you learned before. We explain why this order works, give you one checked free resource and one alternative per topic, and list 5–8 starter problems with the pattern each one teaches.

How to use this page: Work through the topics top to bottom. Don't skip ahead — the ordering matters. For each topic, (1) read the linked resource, (2) solve the starter problems, (3) move on. If a concept feels hard, check our FAQ — it's normal.

Honesty note: Difficulty labels (easy/medium) are our own judgement. "Easy" means a beginner who just read about the topic should be able to approach it with some effort. "Medium" means you may need to think longer or look up the pattern afterwards. Your experience may differ.

Prerequisite: Complexity Basics (Big-O)

Why first? → You need Big-O to evaluate every solution you write. Without it, you can't tell if your approach is efficient enough.

Before any data structure, learn how to express the time and space cost of an algorithm. You don't need to be a mathematician — just understand O(1), O(n), O(n²), and O(log n) with simple examples.

Read our dedicated Complexity Basics page for a fuller explanation.

Recommended Resource

  • Primary: Khan Academy — Asymptotic Notation — visual, beginner-friendly, free. Explains Big-O with clear analogies and step-by-step examples.
  • Alternative: CS Dojo — Introduction to Big O Notation (YouTube) — 15-minute video, good if you prefer watching over reading.

For more resources on all topics, see the Free DSA Resources page.

Arrays

Why second? → Arrays are the simplest data structure. They teach iteration, indexing, and in-place manipulation — skills you'll use in every later topic.

Learn how arrays store elements in contiguous memory, how to traverse them with loops, and common techniques like two pointers, sliding window, and prefix sums.

Recommended Resource

  • Primary: GeeksforGeeks — Array Data Structure Guide — comprehensive written reference covering operations, common problems, and complexity of each operation.
  • Alternative: Kunal Kushwaha — Complete Arrays Tutorial (YouTube) — long-form video with Java examples, popular among Indian students.

Introduction to Dynamic Programming

Why last? → DP combines recursion with optimal substructure. It's the hardest topic for beginners but natural if you've built up recursion and memoisation skills. This is an introduction, not a complete guide.

Recommended Resource

  • Primary: GeeksforGeeks — Dynamic Programming — starts with overlapping subproblems and optimal substructure, then walks through classic DP problems with top-down and bottom-up approaches.
  • Alternative: Aditya Verma — DP Playlist (YouTube) — the most popular DP playlist among Indian engineering students; starts from the recursion-to-DP conversion pattern.

What comes next? This roadmap covers the fundamentals. Once you're comfortable here, explore advanced topics like segment trees, tries, advanced graph algorithms, and harder DP patterns. Check our interview preparation page for a 2-week revision plan that covers these 11 topics.

Summary: Your Learning Path

Here's the full sequence at a glance:

  1. Complexity Basics → learn Big-O
  2. Arrays → iteration, two pointers, sliding window
  3. Strings → character arrays, frequency counting
  4. Searching & Sorting → binary search, merge sort, quick sort
  5. Linked Lists → pointer manipulation, fast-slow technique
  6. Stacks & Queues → LIFO/FIFO, monotonic stacks
  7. Hashing → O(1) lookups, frequency maps, prefix sums
  8. Recursion → base case/recursive case, backtracking
  9. Trees → DFS, BFS, BST operations
  10. Graphs → adjacency representation, BFS/DFS, topological sort
  11. Intro to DP → memoisation, tabulation, classic problems

Estimated time: 3–4 months at 2 hours/day of focused study. Don't rush — understanding beats speed.
